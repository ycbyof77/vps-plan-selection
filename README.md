## 常见问题

### 香港和美国节点怎么选？

看访客在哪。访客主要在国内，选香港 CMI，50 元/月起，延迟低是它最大的优势，代价是端口小、流量少。访客在海外，或者你要跑的是跨境业务，选美国，同样 50 元能拿到 1Gbps 端口和 1TB 流量，带宽资源宽裕得多。两边都要，就各买一台小的，加起来一百元出头。

### 原生 IP 和双 ISP 有什么区别？

原生 IP 说的是这个 IP 归属于当地的运营商，不是转手来的。双 ISP 是在原生 IP 的基础上，让这个 IP 在各大 IP 数据库里同时挂两家运营商，识别出来更像住宅宽带。做 TikTok、跨境电商这类对 IP 纯净度敏感的业务，双 ISP 更稳；只是建站、跑 API，普通原生 IP 就够，没必要为双 ISP 多付钱。

### 月付还是年付划算？

先月付试一个月，确认线路和延迟符合预期，再转年付。年付本身不打折，省钱全靠优惠码，而优惠码能不能用要当场验。反过来说，年付的钱一次性付出去，遇到线路变动或者业务调整就套住了。不确定的业务，月付贵一点但灵活。

### 支持支付宝吗，退款怎么算？

支持支付宝，国内下单没有门槛。常规套餐带 48 小时无理由退款，年付特价这类促销套餐明确写了不适用，下单页面上会标注。买之前把这条看清楚，尤其是打算年付的时候。
